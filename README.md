Инструкция запуска (Через терминал) (Требуется Docker Desktop)
1. Скачать проект
2. ввести в терминал команду "cd (расположение проекта)\tgbot" чтобы перейти к нему в папку
3. ввести "docker compose up --build"

Я лично работаю с PyCharm, так можно просто клонировать репозиторий напрямую из GitHub и вводить "docker compose up --build" в локальный терминал (наличие Docker все равно нужно)

Команда /start регистрирует пользователя

Команда /profile выводит даннные о пользователе (ID, Имя пользователя, дата регистрации в боте)

Других команд пока не предусмотрено
